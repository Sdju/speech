# Macroblocks

Фаза между фактурой и wireframe: **макроблоки**, ещё не слайды.

Метки: `draft` · `ok` · `cut` · `merge?` · `stale`

**Статус каркаса:** `draft` — пересобран под сквозной сценарий Ябе.ру. Старый wireframe в `parts/` = `stale` до перенарезки.

Источник истории: `collected/narrative.md`.

---

## Порядок (предложение)

1. Intro · тон
2. Обещания независимости (зачем люди смотрят на MFE)
3. Рамка бизнес / техника
4. Ябе: рост продукта = лестница архитектур (включая прибытие на MFE)
5. Поворот: почему один frontend?
6. Static vs dynamic · цена dynamic (MS ≠ + техпроблемы)
7. Сопоставление / когда dynamic · артефакт · итог

## Предлагаемый каркас

### MB0 · Intro
**Статус:** `ok` · ~2 мин · parts частично реализованы

- Кто / тема / дисклеймер: MFE != плохо; не хейт.
- Жанр: архитектура; дальше будет сквозная история продукта.

**Зачем:** выровнять ожидания и тон.

---

### MB1 · Что обещают (независимость)
**Статус:** `draft` · ~4 мин · **опора**

- Меню ожиданий: независимые команды/релизы, «масштабируемость», стеки, изоляция доменов…
- Обещание ≠ инструмент; MFE — один из путей.
- Мягко: «часто под этим имеют в виду независимые куски UI в одном продукте»; эталон MF можно посадить здесь **или** отложить до этапа Travel (открытый выбор).

**Зачем:** общий язык желаний до истории.
**Не делать:** глубокую критику и полный контракт static/dynamic здесь.

---

### MB2 · Бизнес и техника
**Статус:** `draft` · ~4 мин · **опора**

- Две плоскости боли/решения.
- Не лечить чисто бизнесовую боль только техникой.
- Примеры можно заранее наметить языком будущего Ябе («две команды в одном релизе», «разный темп доменов») — без полного раскрытия истории.

**Зачем:** метод на весь доклад.
**Выход:** привычка спрашивать плоскость боли.

---

### MB3 · Ябе.ру · лестница (ядро доклада)
**Статус:** `draft` · ~16–18 мин · **опора** · заменяет старые MB5–7 + часть «прибытия на MFE»

Подглавы (не отдельные сухие «+/-» слайды — +/- вшивать в главу):

| | Продукт | Архитектура | ~мин | Каламбур |
|--|---------|-------------|------|----------|
| 3.0 | Ябе.ру / такси | flat | 1.5 | «Я беру такси» — без иронии |
| 3.1 | + Go | modules | 3 | «пробежаться» / я бегу |
| 3.2 | + Еда | monorepo | 3.5 | «ябедам» — пауза → сразу архитектура |
| 3.3 | + Pay | packages | 3.5 | **не дожимать** шутку |
| 3.4 | + Travel | MFE + shell | 4 | «я беру всё» |

На каждом шаге:

- продуктовый повод;
- структура кода / ownership / поставка;
- боль, из‑за которой шаг рационален;
- обновление UI-гэга **без** комментария.

**Зачем:** слушатель сам доезжает до MFE как до логичного предела «как делить».
**Риск темпа:** не раздувать каждую главу двумя слайдами «тезис + плоскости».

---

### MB4 · Поворот
**Статус:** `draft` · ~2–3 мин · **опора**

- Схема: домены × команды × отдельные deploy.
- Вопрос: **А почему всё это до сих пор один frontend?**
- Не «MFE плохие» — вопрос о единстве продукта/проекта.
- Опционально: один раз моргнуть UI-гэгом («архитектура чище — продукт менее очевиден»).
- Якорь: умение добавлять части ≠ ответ, нужно ли их добавлять / держать вместе.

**Зачем:** второй главный вопрос доклада.

---

### MB5 · Static vs dynamic + цена dynamic
**Статус:** `draft` · ~7–8 мин · **опора** · бывшие MB3+MB4, сдвинуты после истории

#### 5a · Ось линковки
- Назвать пройденное: 3.0–3.3 = **static**; 3.4 = **dynamic**.
- Контракт доклада: MFE = dynamic linking (эталон MF).

#### 5b · MS ≠ MFE
- Бизнес-аналогия врёт: scale / эволюция / класс задач.

#### 5c · Техпроблемы runtime (кандидаты; optional cut)
- shared deps / version skew
- контракты и ложная независимость
- UX/perf / стоимость стыков в runtime

**Зачем:** цена последнего прыжка — когда зал уже «хотел» MFE вместе с Ябе.
**Не делать:** DevOps-туториал MF.

---

### MB6 · Сопоставление и когда dynamic
**Статус:** `draft` · ~3–4 мин

- Лестница целиком: где можно остановиться.
- Сигналы «когда dynamic ок».
- Вернуть MB2: не закрывать бизнес-боль только техникой; плюс вопрос MB4 про единство frontend.

---

### MB7 · Артефакт + итог
**Статус:** `draft` · ~3 мин

- Указатель на `example/<example-name>/` (кандидат `yabe`).
- Takeaway: плоскость боли · static-ступени · dynamic имеет цену · два вопроса (как делить / зачем один frontend).
