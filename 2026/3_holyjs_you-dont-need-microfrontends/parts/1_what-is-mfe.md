# Что такое микрофронтенды?

---

**Микрофронтенды** - архитектурный подход к организации проекта, при котором отдельные части проекта разрабатываются, развертываются независимо, но в рамках единого проекта.

<v-clicks>

- Не каждый проект легко разделить на микрофронтенды
- Правильный CI/CD для микрофронтендов может быть сложным
- Правильно настроить Dev-окружение не тривиальная задача
- Сборка является более хрупкой
- Контракты менее четкие
- Поддержание единого стиля
- Массовые миграции

</v-clicks>

---

# Микросервисы != Микрофронтенды

<v-clicks>

- Микрофронтенды - не могут масштабироваться в ширину
- Микрофронтенды - живут в реалиях 1 сайта
- UI это не API который может обновляться независимо

</v-clicks>

---

Что же нам обещают микрофронтенды?

<v-clicks>

- Четкие границы ответственности
- Свои пайплайны в репозитории
- Независимый деплой
- <span class="blur"> Динамическая подгрузка </span>

</v-clicks>
