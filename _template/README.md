# Шаблон доклада

Создавайте доклад из корня репозитория:

```bash
pnpm presentation:create -c <conf> -t "<english-title>" -y <year>
```

Примеры в `parts/`: XSlide, палитра, timeline и схемы, FileTree, SVG-стрелка с управляемой прорисовкой. Это демонстрации возможностей; замените их материалом нового доклада.

Общие улучшения перенесены из `2026/3_holyjs_you-dont-need-microfrontends`:

- `FileTree`: текстовое дерево во frontmatter, стабильные `@id`, переносы файлов, подсветка и автоматический подсчёт кликов.
- Timeline: отдельное состояние для основного слайда и превью докладчика; размонтирование старого экземпляра не удаляет состояние нового.
- `XSlide`: `view-transition-name` на настоящей обёртке, выбор тега через `as`; параметры default-slot сохранены.
- `SvgArrow`: своя траектория `d`, прогресс `reveal` от 0 до 1, синхронная прорисовка пунктирной линии и наконечника. Прежние `coords`, `power` и класс `animate` работают.
- GLSL-фон: изменение uniform-параметров без перекомпиляции шейдеров, освобождение WebGL-контекста, настройки `resolutionScale` и `fps` (по умолчанию 1 и 60).
- Цвет фона корректно считывается и для `layout: full`.

`patches/@slidev__client@52.19.0.patch` подключён через `pnpm-workspace.yaml`: сохраняет экземпляры слайдов при View Transitions, чтобы первый клик после перехода не пропускал анимацию. Штатная отмена перехода при быстрой навигации не оставляет необработанный `AbortError`. При обновлении Slidev проверьте, нужен ли патч новой версии, и адаптируйте его вместе с lockfile.

3D-сцена, камеры, HUD, данные, изображения и предметные компоненты остаются в исходном докладе. Их зависимости `three` и `@types/three` шаблону не нужны. Палитра и оформление шаблона сохранены.
